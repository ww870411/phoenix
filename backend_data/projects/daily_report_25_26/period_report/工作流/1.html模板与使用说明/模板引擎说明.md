# 大连洁净能源集团周期生产运行汇报 HTML 演示引擎：页面结构与 AI Agent 接口开发规范 (V2.5)

本规范文档定义了一套适配 16:9 宽屏投影、8:3 异形大屏预压与桌面审阅的 **HTML 交互式生产运行汇报引擎标准**。AI Agent 在接收到**《生产数据明细.xlsx》**与**《汇报材料结构与要求.md》**后，须严格遵循本规范与配套的 8 页标准母版 `模版引擎.html`，生成单文件自包含（Single-File Self-Contained）的 HTML 汇报页面。

## 第一部分：汇报页面整体结构与实用化命名原则（P1—P8 标准 8 页架构）

> [!IMPORTANT]
> **平实直观、简单实用原则**：
> 页面标题、顶部徽章、指标卡片及导读小标题必须采用**通俗易懂、贴合供暖生产实际的平实业务语言**（如“一、基本概况”、“重点指标”、“核心要点 1”、“补充说明 1”），**严禁在页面可见文字中出现“谱系扫描要点”、“北极星 KPI”、“Bento 矩阵”、“L1—L4 金字塔深潜”等生造玄幻词汇**，确保参会人员一目了然。

## 第二部分：数据呈现与行文五项准则

1. **客观平实陈述**：每个段落（`.reading-para`）首句用 `<strong>` 概括核心事实，正文客观列出“本期数值、同比增加/减少量、增幅/降幅%”，不做主观褒贬判断，不使用括号硬塞同比差异。
2. **严格执行“红增绿减”**：正文中所有同比增加/上升数值包裹 `<span class="num-pos">`（红字浅红底），所有同比减少/下降数值包裹 `<span class="num-down">`（绿字浅绿底）；表格差异列正值用 `text-red-700 font-bold`，负值用 `text-teal-700 font-bold`；图表中增加统一用红色（`#dc2626`），减少统一用绿色（`#16a34a`）。
3. **均值红线直观对标**：单耗对标图统一绘制全集团均值红虚线（`markLine`），直观反映各单位单耗与集团平均水平的差异。
4. **期间计划分解测算标注“参考”**：在涉及期间计划分解测算值的表头与说明中，明确标注“期间计划测算(参考)”，与官方固定的“月度计划值”区分。
5. **气温实测与预测严格切分**：P1 首页《图1》仅绘制当期统计实测期的每日平均气温与同期对比；《每日气温明细》中的后 7 日预测数据专门置于 P8 右下图展示。

## 第三部分：HTML 模板引擎 DOM 契约与组件接口

AI Agent 在基于 `模版引擎.html` 生成新页面时，**保持 `<style>` 样式表与 `<script>` 前半部分交互内核不变**，仅替换标题插槽、`<main id="slidesViewport">` 内的 8 个 `<section class="slide-page">` 以及 `CHART_REGISTRY` 图表配置。

### 3.1 语义化数字标签契约（红增绿减）

| CSS 类名 | 视觉效果 | 适用业务场景 | HTML 写法示例 |
| :--- | :--- | :--- | :--- |
| `.num-pos`<br/>`.num-up` | **浅红底深暗红粗体**<br/>(`text-red-700 bg-red-50`) | **增加为红色**：同比增加、增幅为正 | `<span class="num-pos">197.20万元</span>`<br/>`<span class="num-pos">9.24%</span>` |
| `.num-down`<br/>`.num-dec` | **浅绿底深青绿粗体**<br/>(`text-emerald-700 bg-emerald-50`) | **减少为绿色**：同比减少、降幅为负 | `<span class="num-down">981吨</span>`<br/>`<span class="num-down">7.83%</span>` |
| `.num-warn` | **浅黄底深琥珀粗体**<br/>(`text-amber-800 bg-amber-50`) | **重点提示**：高于均值提示或降温提示 | `<span class="num-warn">-0.80℃</span>` |

### 3.2 首列冻结数据表与一键宽屏放大契约 (`.report-table` & `.expand-table-btn`)

在 P4—P8 分屏页左栏放入 `.expand-table-btn` 按钮与 `.data-table-wrap` 表格后，引擎会在页面加载时自动生成右侧宽屏大字放大层：

```html
<div class="panel-toolbar">
  <span class="text-xs font-bold text-slate-700">📄 章节讲稿 & 附表</span>
  <button type="button" class="expand-table-btn px-2.5 py-1 rounded bg-sky-800 hover:bg-sky-700 text-white text-xs font-semibold transition">🔍 右侧宽屏放大附表</button>
</div>
```

## 第四部分：ECharts 图表注册接口 (`CHART_REGISTRY`) 与配色规范

1. **懒加载注册机制**：所有图表按页面的 `data-slide-index`（`0` 至 `7`）注册在 `CHART_REGISTRY` 中，切页后自动初始化并重算尺寸。
2. **统一色板常量（`THEME`）**：
   - 本期实际主序列：深海蓝 `THEME.NAVY` (`#14446b`)
   - 同期对比序列：暖金黄 `THEME.GOLD` (`#f3c677`) 配深琥珀边框 `THEME.GOLD_BORDER` (`#b45309`)
   - 同比增加 / 均值红线：标准红 `THEME.RED` (`#dc2626`)
   - 同比减少：标准绿 `THEME.GREEN` (`#16a34a`)
3. **预设工厂函数（`ChartPresets`）**：
   - `ChartPresets.temperatureCurve(dates, avgTemps, priorAvgTemps)`：首页必配每日平均气温与同期双线对比图；
   - `ChartPresets.divergingBar(categories, values, yName, minVal, maxVal)`：主要指标同比增减幅排序柱状图（`v >= 0` 自动标红，`v < 0` 自动标绿）；
   - `ChartPresets.groupedComparisonBar(categories, currentData, priorData, yName, currentName, priorName, markLineValue, markLineLabel)`：本期与同期分组对比柱状图（支持可选集团均值红虚线）。

## 第五部分：8:3 异形大屏预压模式与在线文字编辑保存

1. **8:3 异形巨幕反向预挤压（快捷键 `8`）**：点击顶栏 `🖥️ 8:3 预压` 或按键盘 `8`，页面按 150% 超宽排版并执行水平 $2/3$ 预压缩（`scaleX(0.6666667)`），输出至 8:3 拼接大屏拉伸 1.5 倍后恢复 1:1 标准几何比例。
2. **所见即所得在线文字编辑与保存（快捷键 `E` / `Ctrl+S`）**：点击顶栏 `✏️ 编辑`（或按 `E` 键）可直接修改左栏念稿文字，按 `Ctrl+S`（或点击 `💾 保存`）自动脱水清理并原位覆盖保存。
