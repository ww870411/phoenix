# 供暖集团周期生产运行汇报自动化工作流（Master Prompt 双轨输出总控指令）

## 一、 项目背景与“一源双轨”工作流设计架构

本工作流旨在解决供暖集团周期性生产调度汇报中“传统系统只会机械算数、不懂供暖业务逻辑与跨维归因”以及“上会演示与领导纸质审阅形态割裂”两大痛点。

通过将**确定性的数据平台统计能力**、**结构化的行业领域知识库**与**大语言模型（LLM）的逻辑推理及代码生成能力**深度耦合，构建了**“一套数据源与业务逻辑，同步驱动生成【16:9 交互投屏 HTML】与【标准公文图文版 DOCX】”**的四步自动化工作流：

1. **第一步：构建双轨输出容器规范（展示与排版引擎层）**
   * **大屏投屏轨（HTML）**：提供单文件自包含的 16:9 宽屏演示引擎（`1.html模板与使用说明/模版引擎.html`）与《模板引擎说明》（`1.html模板与使用说明/模板引擎说明.md`），封装 L1–L4 金字塔叙事、A–E 五大版式、首列冻结附表宽屏放大、分类筛选与 ECharts 图表注册机制。
   * **纸质呈批轨（DOCX）**：遵循国企标准公文排版规范与高清静态统计图嵌入标准（详见本文第四部分），通过自动化脚本（如 Python `python-docx` + `matplotlib`）或文档生成工具输出可直接双面打印呈送公司领导的 `.docx` 汇报材料。
2. **第二步：从综合数据平台导出多维业务源数据（事实与数据层）**
   * 根据用户选定的任意统计周期（单周、多日、旬度、月度或自定义日期区间），从平台导出存放于 `2.数据来源/` 的《周期生产运行多维指标对标全景表》（.xlsx）。
   * 支持动态扩展并关联导出《主设备工况与开停机时序表》、《辽宁电力现货15分钟电价表》、《生产调度发令与管网抢修工作票表》等高维明细数据。
3. **第三步：注入供暖行业业务逻辑与简报内容规范（大脑与规则层）**
   * 提供《供暖集团周期生产运行简报 AI Agent 生成规范与业务逻辑说明书 (V2.1)》（`3.材料结构与要点/汇报材料结构与要求.md`）与《本期重点关注要点》（`3.材料结构与要点/重点关注.md`）。
   * 明确集团组织架构管理口径（集团汇总、主城区[北海热电、香海热电、供热公司]、金州热电、北方热电、金普公司、庄河环海、研究院）、五大标准业务章节、9 大供暖行业核心归因法则（`HDD20` 采暖度日数对标、实际与可比煤价边际利润剥离、耗煤量直接对比、电力现货负电价与高减压器联动、厂网水电耗剥离、无依据不强行归因、省市平台投诉量与当日净投诉量累计合计分析等）及数据精度红线。
4. **第四步：AI Agent 自动化编排、跨表归因与双轨成品交付（执行与输出层）**
   * AI Agent 接收上述三步材料，执行一次性的核心数据核算与跨表归因，**同步生成两份同源同数、逻辑一致的交付物**：
     * **交付物 1**：用于会议室大屏投屏演示的交互式 `.html` 汇报页面；
     * **交付物 2**：用于打印呈送公司领导审阅的图文并茂标准公文格式 `.docx` 汇报文档（或可直接运行生成该 `.docx` 的完整 Python 自动化构建脚本）。

## 三、 AI Agent 核心推理与生成序列（五步内部 SOP）

收到上述材料后，请严格按照以下 5 个阶段依次推进：

### 阶段 1：源数据扫描与核心衍生指标预计算（一源同算）
1. **识别统计周期与对比维度**：读取《多维指标对标全景表》表头，确认当前统计起止日期、天数及对比同期日期；检查是否包含“上期/环比”列（若有则同环比并重，若无则聚焦同比与期间计划分解测算完成率）。
2. **测算 `HDD20` 采暖度日数基准**：读取主城区平均气温（`aver_temp_main_city`），按 $\text{HDD}_{20} = \max(20 - T_{\text{日均}}, 0)$ 计算本期、同期（及上期）的日均及累计 $\text{HDD}_{20}$，并算出 **`HDD20` 同比（及环比）变化率%**，作为全篇供热量、标煤耗量、高温水销量及热单耗的理论对标基准线。
3. **测算服务质量“期间投诉合计值”**：读取各单位及集团汇总的 `省市平台投诉量`（`amount_daily_service_complaints`）与 `当日净投诉量`（`amount_daily_net_complaints`），计算选定期间累计的**两项投诉合计值（`省市平台投诉量 + 当日净投诉量`）**及其同比增减量与变化率%。
4. **校验特殊口径与未结算项**：确认 `ZhuChengQu（主城区）` 与 `BeiHai + XiangHai + GongRe` 的聚合及内部售热收入抵消关系；检查是否存在供热量大于 0 但标煤与外购热均为 0 的未结算单位（如庄河环海），准备免责提示说明。

### 阶段 2：跨表证据链对齐与行业法则归因
1. 调用《汇报材料结构与要求.md》中的 **9 大核心业务归因法则**，对五大章节指标进行深度剖析。
2. **优先响应《重点关注.md》专项指引**：
   * 每次推理开始时，优先读取《重点关注.md》文本；
   * 若其中注明了当期重点分析的单位、特定事件（如“深谷负电价高减调峰”、“某电厂倒炉水耗”、“某单位管网漏水闭环”）或管理指示，Agent 必须将该专项要点作为核心主线之一，在对应的业务章节深入展开穿透剖析，并在第一章总纲中重点提及；
   * 若《重点关注.md》为空（或无特殊要点），则严格按照标准全景归因规则推进，确保输出全面客观。
3. **严格执行【客观证据链原则（无依据不强行归因）】**：
   * 若当期提供了开停机表、现货电价表、调度指令与抢修票表，必须通过时间戳与单位名称将具体机炉启停、`#X高减`投退、管道消缺、管网漏水抢修位置精准锚定到对应指标波动中；
   * 若当期未提供上述扩展日志表，或某项指标异常在日志中无明确记录佐证，**严禁主观臆测或编造现场原因**，必须客观陈述数据异常事实并下达专项核查要求。
4. **执行名称标准化与数据精度规范**：
   * 全文（含 HTML 与 DOCX）将源表的“集团全口径汇总”统一标准化为 **“集团汇总”**；
   * 正文中金额（万元）、标煤耗量（吨）、供热量/外购热量（GJ）、耗水量（吨）数值 **大于 1000 时统一取整**（小于 1000 时保留 1~2 位小数）；单耗、电耗（万kWh）、气温（℃）、百分比（%）统一保留 **2 位小数**（水单耗若源表为整数则取整）；表格中严格保持与源表一致的精度。

### 阶段 3：生成交付物 A —— 16:9 交互式大屏演示文件 (`.html`)
将五大业务章节映射至《模板引擎说明.md》的 L1–L4 版式中（编排 6～7 页幻灯片）：
* **P1（版式 A）**：报告主标题、核心定性总纲、6 张北极星 KPI 卡片及 5 张核心结论 Bento 卡片。
* **P2（版式 B）**：左栏“一、基本概况与气象复盘”念稿；右上 15～18 项核心指标同比变化率排序谱系图（带 `HDD20` 基准线），右下耗水与耗电结构对比图。
* **P3（版式 C）**：左右双栏呈现“集团汇总”全量指标全景表，配顶部分类高亮筛选器（`data-table-filter`）。
* **P4（版式 D1）**：左栏“二、标煤耗量、外购热与运行调度情况”正文及对标表；右栏标煤同比减量贡献瀑布图及“供热同比 vs 标煤同比 vs `HDD20` 基准”对比图。
* **P5（版式 D2）**：左栏“三、产销边际利润与成本归因分析”正文及利润表；右栏边际利润驱动因子正负条形图及各单位实际/可比煤价边际利润对比图。
* **P6（版式 E）**：左栏“四、供暖单耗与服务质量对标分析”正文及单耗投诉表；右栏 `data-view-switch` 四宫格展示热单耗、电单耗、水单耗及期间投诉量（省市平台+净投诉合计）对标图。
* **P7（版式 D1）**：左栏“五、计划完成情况与下步工作要求”正文及计划完成表；右栏“供热计划完成率 vs 标煤计划完成率”剪刀差图及节煤裕度图。

### 阶段 4：生成交付物 B —— 呈送领导审阅的标准公文图文版 (`.docx`)
基于与 HTML 完全一致的五大章节文本、表格与图表数据，严格按照下方**《第四部分：DOCX 领导汇报材料公文排版与图文并茂规范》**生成 `.docx` 文档。

### 阶段 5：交付前双轨强制自检
核对 HTML 与 DOCX 两份产出物的数据一致性、精度合规性、零占位符以及排版/图表渲染完整性。

## 四、 DOCX 领导汇报材料公文排版与图文并茂规范（强制标准）

在生成 `.docx` 汇报文件时，必须 100% 遵守以下公文格式与图表嵌入规范：

### （一） 页面设置
1. **纸张**：A4（21.0厘米 × 29.7厘米），纵向。
2. **页边距**：上 **3.7厘米**，下 **3.5厘米**，左 **2.8厘米**，右 **2.6厘米**（正文版心有效宽度为 **15.6厘米**）。
3. **页眉**：不设置装饰性页眉（无页眉横线与页眉文字）。

### （二） 文档主标题
1. **字体**：方正小标宋简体。
2. **字号**：二号（22磅）。
3. **颜色**：黑色（`#000000`）。
4. **对齐**：居中对齐，可根据标题长度分为两行排列。
5. **行距与间距**：行距固定值 **30磅**；段前 **0磅**，段后 **14磅**。
6. **缩进与修饰**：无首行缩进，不添加下划线或任何装饰线。

### （三） 正文段落
1. **字体**：仿宋（或 `仿宋_GB2312`；西文与数字可搭配仿宋或 `Times New Roman`）。
2. **字号**：三号（16磅）。
3. **颜色与字重**：黑色，常规字重（正文中不渲染彩色背景胶囊，保持庄重素雅公文风貌）。
4. **对齐与缩进**：两端对齐；首行缩进 **2字符**（32磅）。
5. **行距与间距**：行距固定值 **28磅**；段前、段后间距均为 **0磅**。

### （四） 标题层级
1. **一级标题**：使用“一、……”编号，**黑体，三号（16磅）**，常规字重。
2. **二级标题**：使用“（一）……”编号，**仿宋，三号（16磅），加粗**。
3. **三级标题**：使用“1.……”编号，**仿宋，三号（16磅），加粗**。
4. **段落与缩进**：各级标题均**首行缩进 2字符**，固定行距 **28磅**，段前、段后均为 **0磅**。
5. **防断页控制**：所有层级标题必须启用**“与下段同页（`keep_with_next = True`）”**，严禁标题单独出现在页面最末行。

### （五） 计算公式
1. **排版**：独立成段，居中对齐，无首行缩进，行距固定值 28磅（或单倍行距防止上下截断）。
2. **字体与字号**：仿宋，**14磅**（可根据公式长度适当微调）。
3. **内容要求**：优先使用可编辑的文字公式或 Word 原生公式（OMML）；公式中的指标名称、运算符号和计量单位应清楚完整（如：$\text{HDD}_{20}\text{ 同比增幅(\%)} = (\text{本期HDD}_{20} - \text{同期HDD}_{20}) \div \text{同期HDD}_{20} \times 100\%$、$\text{期间投诉合计(件)} = \text{省市平台投诉量} + \text{当日净投诉量}$）。

### （六） 表格规范
1. **位置与宽度**：表格在页面内水平居中，总宽度严格控制在版心宽度内（**不超过 15.6厘米**）。
2. **列宽分配**：根据各列文字与数值长度合理分配列宽（如首列单位名称适当加宽），避免机械等宽导致数字折行。
3. **字体与字号**：**仿宋，小四（12磅）**。
4. **表头样式**：表头文字**加粗**，填充**浅灰色底纹**（如 `#EDEDED` 或 `#F2F2F2`），黑色文字。
5. **边框样式**：外边框及内部网格线均使用**灰色细实线**（`0.5磅`，颜色 `#808080` 或 `#999999`）。
6. **对齐方式**：单元格内容**水平居中、垂直居中**；首列单位层级从属缩进或较长说明文字可设为左对齐。
7. **单元格段落与行高**：单元格内段前、段后均为 **0磅**，行距**固定值 19磅**；行高随内容自动调整，严禁设置会截断多行表头文字的固定行高。
8. **跨页控制**：启用**“在各页顶端以标题行形式重复出现（`tblHeader`）”**，并设置**“允许跨页断行 = 否（`cantSplit`）”**，确保同一行不跨页拆分。
9. **表下注释**：紧随表格下方，使用**仿宋，小四（12磅）**，无首行缩进，行距固定值 20磅（如庄河环海未结算外购热注释）。
10. **数值精度**：表格内数值统一精度、明确计量单位；计算过程使用原始精度，最终展示时四舍五入。

### （七） 图文并茂：静态统计图表嵌入规范（专为纸质打印优化）
为确保纸质文档直观易读，应在五大章节正文中对应穿插嵌入 **4～5 幅高分辨率（$\ge 300\text{ DPI}$）统计图表**：
1. **标准配图清单**：
   * **第一章配图**：《图1 统计周期主城区气温对比与 HDD20 采暖度日数及核心指标同比变化图》
   * **第二章配图**：《图2 各单位标煤耗量同比增减分解及计划完成率对比图》
   * **第三章配图**：《图3 产销边际利润同比变动驱动因素及各单位可比煤价边际利润对比图》
   * **第四章配图**：《图4 各单位供暖热、电、水单耗（含集团均值线）及期间投诉量合计对标图》
   * **第五章配图**：《图5 各单位期间标煤耗量计划分解测算值与实际完成对比图》
2. **纸质图表视觉规范**：
   * **画布与排版**：纯白背景（`#FFFFFF`），无外框阴影；图片段落居中对齐、**无首行缩进**，图片宽度设为 **14.8厘米～15.4厘米**（与版心及表格宽度对齐），段前 6磅、段后 4磅。
   * **直接显示数据标签**：因纸质打印无法鼠标悬停看数，所有柱状图、折线图、瀑布图必须**强制开启数据标签（Data Labels）**，字号清晰、不重叠。
   * **打印友好配色**：采用高对比度商务色系（深海蓝 `#14446B`、暖琥珀 `#D97706`、深青绿 `#0F766E`、警示红 `#C83E37`），即使在黑白激光打印机下也能通过深浅灰阶与虚实线清晰区分。
   * **图题（图注）格式**：置于图表正下方，居中对齐，无首行缩进，**仿宋，小四（12磅），加粗**，行距固定值 22磅，段后 6磅；图片段落须设置 `keep_with_next = True` 确保图片与下方图题不跨页分离。

### （八） 页码设置
1. **位置与奇偶页**：页码设置在页脚，位于双面打印时每页的外侧；必须启用**“奇偶页不同”**：**奇数页右对齐，偶数页左对齐**。
