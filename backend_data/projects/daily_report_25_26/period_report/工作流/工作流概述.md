# 大连洁净能源集团周期生产运行汇报自动化工作流（Master Prompt 双轨输出总控指令）

## 一、 项目背景与“一源双轨”工作流设计架构

本工作流旨在解决大连洁净能源集团周期性生产调度汇报中“传统系统只会机械算数、不懂供暖业务逻辑与跨维归因”以及“上会演示与领导纸质审阅形态割裂”两大痛点。

通过将**确定性的数据平台统计能力**、**结构化的行业领域知识库**与**大语言模型（LLM）的逻辑推理及代码生成能力**深度耦合，构建了**“一套数据源与业务逻辑，同步驱动生成【16:9 交互投屏 HTML】与【标准公文图文版 DOCX】”**的四步自动化工作流：

1. **第一步：构建双轨输出容器规范（展示与排版引擎层）**
   * **大屏投屏轨（HTML）**：提供单文件自包含的 16:9 宽屏演示引擎（`1.html模板与使用说明/模版引擎.html`）与《模板引擎说明》（`1.html模板与使用说明/模板引擎说明.md`），封装 L1–L4 金字塔叙事、A–E 五大版式、首列冻结附表宽屏放大、分类筛选、8:3 异形巨幕预压切换（快捷键 `8`）与 ECharts 图表注册机制。**首页必须嵌入期间每日平均气温与同期对比曲线图（仅展示本期和同期的每日平均气温双线对比，不再展示最高、最低气温）**。
   * **纸质呈批轨（DOCX）**：遵循国企标准公文排版规范与高清静态统计图嵌入标准（详见本文第四部分），**文档标题严格采用两行形式（第一行“大连洁净能源集团”，第二行“XX月XX日—XX月XX日生产运行情况简报”）**，概述部分嵌入期间每日平均气温与同期对比曲线图（仅展示本期与同期日均气温双线对比），通过自动化脚本或文档生成工具输出可直接双面打印呈送公司领导的 `.docx` 汇报材料。
2. **第二步：从综合数据平台导出多维业务源数据（事实与数据层）**
   * 根据用户选定的任意统计周期（单周、多日、旬度、月度或自定义日期区间），从平台导出存放于 `2.数据来源/` 的 `生产数据明细.xlsx` 数据包（已原生内嵌 5 张核心工作表：指标全景、机炉时序、现货电价、调度发令抢修、以及新增的《每日气温明细》）。
   * 支持动态扩展并关联导出《主设备工况与开停机时序表》、《辽宁电力现货15分钟电价表》、《生产调度发令与管网抢修工作票表》等高维明细数据。
3. **第三步：注入供暖行业业务逻辑与简报内容规范（大脑与规则层）**
   * 提供《大连洁净能源集团周期生产运行简报 AI Agent 生成规范与业务逻辑说明书 (V2.1)》（`3.材料结构与要点/汇报材料结构与要求.md`）与《本期重点关注要点》（`3.材料结构与要点/重点关注.md`）。
   * 明确集团组织架构管理口径（集团汇总、主城区[北海热电、香海热电、供热公司]、金州热电、北方热电、金普公司、庄河环海、研究院）、六大标准业务章节、9 大行业核心归因法则（`HDD20` 对标、实际与可比煤价边际利润剥离、耗煤量直接对比、电力现货负电价与高减压器联动、厂网水电耗剥离、客观证据链归因、省市平台总投诉量与考核净投诉量双轨独立分析、数值差异逗号公文句式等）及数据精度红线。
4. **第四步：AI Agent 自动化编排、跨表归因与双轨成品交付（执行与输出层）**
   * AI Agent 接收上述三步材料，执行一次性的核心数据核算与跨表归因，**同步生成两份同源同数、逻辑一致的交付物**：
     * **交付物 1**：用于会议室大屏投屏演示的交互式 `.html` 汇报页面；
     * **交付物 2**：用于打印呈送公司领导审阅的图文并茂标准公文格式 `.docx` 汇报文档（或可直接运行生成该 `.docx` 的完整 Python 自动化构建脚本）。

## 三、 AI Agent 核心推理与生成序列（五步内部 SOP）

收到上述材料后，请严格按照以下 5 个阶段依次推进：

### 阶段 1：源数据扫描与核心衍生指标预计算（一源同算）
1. **识别统计周期与对比维度**：读取《多维指标对标全景表》表头，确认当前统计起止日期、天数及对比同期日期；检查是否包含“上期/环比”列（若有则同环比并重，若无则聚焦同比与期间计划分解测算完成率）。
2. **提取逐日气温与测算 `HDD20` 采暖度日数基准**：
   - 直接读取子工作表**《每日气温明细》**，提取选定周期内每日最高气温、最低气温、平均气温以及对应的同期日期和同期平均气温；
   - 提取的本期日均温与同期日均温序列直接用于渲染《图1 期间每日平均气温与同期对比曲线图》；
   - 按 $\text{HDD}_{20} = \max(20 - T_{\text{日均}}, 0)$ 计算本期、同期（及上期）的日均及累计 $\text{HDD}_{20}$，并算出 **`HDD20` 同比（及环比）变化率%**，作为全篇供热量、标煤耗量、高温水销量及热单耗的理论对标基准线。
3. **统计服务质量“省市平台总投诉量”与“住建局考核净投诉量”（双轨独立，严禁相加）**：
   * 读取各单位及集团汇总的 `amount_daily_service_complaints`（省市平台总投诉量，体现接入的全部诉求总负荷全貌）与 `amount_daily_net_complaints`（净投诉量，体现确认为有效且解决完毕、计入住建局考核的投诉量）；
   * **两项指标并非并列关系，严禁将二者相加求和（绝不计算所谓的“期间投诉合计值”）**！分别统计选定期间各自累计值及同环比增减幅度。
4. **校验特殊口径与未结算项**：内部结算与各单位核算口径已为内部默契共识，检查是否存在供热量大于 0 但标煤与外购热均为 0 的未结算单位（如庄河环海），准备简要标注。

### 阶段 2：跨表证据链对齐与行业法则归因
1. 调用《汇报材料结构与要求.md》中的 **9 大核心业务归因法则**，对六大章节指标进行深度剖析。
2. **优先响应《重点关注.md》专项指引**：
   * 每次推理开始时，优先读取《重点关注.md》文本；若注明了重点分析单位或特定事件，Agent 必须将该专项作为主线之一深入剖析并在总纲中重点提及。
3. **严格执行【客观证据链原则（无依据不强行归因）】**：
   * 若当期提供了开停机表、现货电价表、调度指令与抢修票表，必须精准锚定到对应指标波动中；
   * 若无明确记录佐证，**严禁主观臆测或编造现场原因**，仅客观陈述数据事实并提示核查。
4. **执行四大行文红线与防错准则**：
   * **【集团全称与名称统一】**：集团全称使用“大连洁净能源集团”；源表“集团全口径汇总”全文统一标准化为 **“集团汇总”**。
   * **【严禁口径解释】**：在 HTML 和 DOCX 汇报中，**严禁出现任何对口径的解释性文字**（各单位口径已为集团内部默契，报告只讲数据、归因与结论）。
   * **【严禁暴露提示词与内部法则】**：**严禁出现如“严格执行法则05……”、“根据法则01……”、“按照提示词要求……”等暴露系统指令、业务法则编码的词汇**！所有逻辑自然融入政企公文语境。
   * **【红增绿减】**：图表配色与差异率/增减幅文字字体严格执行**增加为红色、减少为绿色**。
   * **【数据精度规范】**：正文中金额（万元）、标煤耗量（吨）、供热量/外购热量（GJ）、耗水量（吨）数值 **大于 1000 时统一取整**；单耗、电耗（万kWh）、气温（℃）、百分比（%）统一保留 **2 位小数**。

### 阶段 3：生成交付物 A —— 交互式演示文件 (`.html`，留存完整讲稿 + 生动图表一目了然)
* **HTML 文件的核心意义与双轨定位**：
  - HTML 演示框架绝非单纯罗列几个干瘪的数据卡片，而是**“大屏生动呈现 + 完整同款讲稿”**的汇报中枢；
  - **左栏念稿面板（`.script-scroll`）**：**必须完整保留与下方 DOCX 完全相同的全部精炼段落讲稿（逻辑同款、一字不漏）**，使主讲人在大屏前汇报时有完整、规范的讲稿可念，所读即为领导手中 DOCX 文档原文；
  - **右栏视觉面板（`.visual-panel`）**：同屏生动展示高对比度 ECharts 交互图表与全屏放大表格，让参会听众抬眼即可“一目了然”看清数据变化与异动根因。
* **双模视口兼容**：默认支持 **16:9 标准比例**；同时内嵌 **8:3 异形大屏投影模式**（快捷键 `8` 一键预挤压 $2/3$，大屏拉伸后呈现完美 1:1 满屏巨幕）；
* **P1（版式 A · 首页总览）**：
  - 报告主标题展示为“大连洁净能源集团 [XX月XX日—XX月XX日] 生产运行情况简报”；
  - 核心定性总纲；
  - 6 张北极星 KPI 卡片（含平均气温及 HDD20 增幅、供热量、标煤耗、边际利润、省市平台总投诉量、住建局考核净投诉量；两项投诉指标分列展示，严禁相加）；
  - **【首页核心曲线图】期间每日平均气温与同期对比曲线图**（仅展示本期和同期日均气温双线对比，不需展示最高、最低气温）；
  - 4 张核心结论结构化 Bento 卡片。
* **P2（版式 B）**：左栏完整保留“一、基本概况与气象复盘”讲稿；右上 15～18 项核心指标同比变化率排序谱系图（红增绿减，带 `HDD20` 基准线），右下耗水与耗电结构对比图。
* **P3（版式 C）**：左右双栏呈现“集团汇总”全量指标全景表，配顶部分类高亮筛选器（`data-table-filter`）。
* **P4（版式 D1）**：左栏完整保留“二、标煤耗量、外购热与运行调度情况”讲稿及对标表；右栏标煤同比减量贡献瀑布图及“供热同比 vs 标煤同比 vs `HDD20` 基准”对比图。
* **P5（版式 D1，新增章节）**：左栏完整保留“三、发电量与电力现货市场情况”讲稿及各热电厂发售电对标表；右栏展示期间辽宁电力现货每日 96 点实时出清电价高频波动全景走势图（标明深谷负电价区间与高峰电价窗口）。
* **P6（版式 D2）**：左栏完整保留“四、产销边际利润与成本归因分析”讲稿（主体段落 5 聚焦可比煤价边际利润统领成本四要素；辅助段落 6 点名各单位可比利润并在段末独立单起一句交代边际利润，两名固定绝不混写）及利润表；右栏边际利润驱动因子正负条形图及各单位可比利润对比图。
* **P7（版式 E）**：左栏完整保留“五、供暖单耗与服务质量对标分析”讲稿（正文客观陈述省市平台投诉量与考核净投诉量，严禁正文出现“严禁相加”字样）及单耗投诉表；右栏 `data-view-switch` 四宫格展示热单耗、电单耗、水单耗及投诉量（省市平台总投诉量 vs 住建局考核净投诉量双柱对标，严禁相加）对标图。
* **P8（版式 D1）**：左栏完整保留“六、计划完成情况与下步工作要求”讲稿及计划完成表；右栏“供热计划完成率 vs 标煤计划完成率”剪刀差图及节煤裕度图。
* **在线文字编辑与双模持久化保存**：内置所见即所得编辑器（顶栏 `✏️ 编辑` 与 `💾 保存` 按钮，快捷键 `E` 切换编辑，`Ctrl+S` 随时保存）。左栏念稿正文与标题支持直接打字润色修改；系统内打开自动调用后端 API 覆写服务器材料仓库物理文件，脱离平台时自动触发离线另存与 LocalStorage 记忆。

### 阶段 4：生成交付物 B —— 呈送领导审阅的标准公文图文版 (`.docx`)
* **基准范本与篇幅硬熔断**：以 `backend_data/projects/daily_report_25_26/period_report/材料仓库/第十二周生产运行简报.docx` 为黄金基准，严格遵循“表看全貌，文抓异常”；
* **分析主线与三大辅助工具定位**：以真实生产运行大盘为主线；HDD20、计划分解测算值、调度信息三项内容**仅作为锦上添花、按需补充佐证使用，严禁反客为主作为叙事骨架**；
* **篇幅与字数上限**：正文总段落数**严格锁定为 11～13 个精要自然段**，文字约 **1600～2300 字**，打印版面严格为 **5～6 页 A4 纸**（绝对严禁超过 7 页，坚决杜绝 20+ 页冗长流水账）；
* **数值差异强制公文句式**：全文指标同环比差异描述严格执行“`标煤耗量8,807吨，同比减少1,210吨，降幅12.08%`”标准句式，**严禁使用括号硬塞比较**；
* 基于与 HTML 左栏完全相同的文本段落、7 张标准表格与 5～6 幅高清统计图表，严格按照下方**《第四部分：DOCX 领导汇报材料公文排版与图文并茂规范》**生成 `.docx` 文档。

## 四、 DOCX 领导汇报材料公文排版与图文并茂规范（强制标准）

在生成 `.docx` 汇报文件时，必须 100% 遵守以下公文格式与图表嵌入规范：

### （一） 页面设置
1. **纸张**：A4（21.0厘米 × 29.7厘米），纵向。
2. **页边距**：上 **3.7厘米**，下 **3.5厘米**，左 **2.8厘米**，右 **2.6厘米**（正文版心有效宽度为 **15.6厘米**）。
3. **页眉**：不设置装饰性页眉（无页眉横线与页眉文字）。

### （二） 文档主标题
1. **字体**：方正小标宋简体。
2. **字号**：二号（22磅）。
3. **颜色**：黑色（`#000000`）。
4. **对齐与分行**：居中对齐，**必须严格分为两行排列**：
   - 第一行：`大连洁净能源集团`
   - 第二行：`XX月XX日—XX月XX日生产运行情况简报`
   （示例：`大连洁净能源集团\n11月1日—11月5日生产运行情况简报`，中间统一使用一字线“—”连接起止日期）。
5. **行距与间距**：行距固定值 **30磅**；段前 **0磅**，段后 **14磅**。
6. **缩进与修饰**：无首行缩进，不添加下划线或任何装饰线。

### （三） 正文段落
1. **字体**：仿宋（或 `仿宋_GB2312`；西文与数字可搭配仿宋或 `Times New Roman`）。
2. **字号**：三号（16磅）。
3. **颜色与字重**：黑色，常规字重（正文中不渲染彩色背景胶囊，保持庄重素雅公文风貌）。
4. **对齐与缩进**：两端对齐；首行缩进 **2字符**（32磅）。
5. **行距与间距**：行距固定值 **28磅**；段前、段后间距均为 **0磅**。
6. **行文红线约束**：
   - **数值差异强制公文句式**：全文同环比差异描述严格写为“`标煤耗量8,807吨，同比减少1,210吨，降幅12.08%`”标准句式，**严禁使用括号硬塞差异比较**；动词统一使用“同比增加/减少”，比例统一使用“增幅/降幅”；
   - **严禁出现口径解释**（主城区内部抵消、未设庄河可比煤等业务口径已是内部默契，报告绝不罗嗦口径背景）；
   - **严禁暴露提示词、法则编号与负向系统指令**（不仅严禁出现诸如“严格执行法则05”、“根据法则01”，**更绝对禁止将“严禁将两项投诉量指标相加”、“未作合并”等后台指令抄进正文**）；
   - **利润指标两名固定与分段物理隔离**（主体为“可比煤价边际利润”，辅助为“边际利润”，段落 5 不出现边际利润，段落 6 末尾独立一句，严禁自创“账面边际利润”）。

### （四） 标题层级
1. **一级标题**：使用“一、……”编号，**黑体，三号（16磅）**，常规字重。
2. **二级标题**：使用“（一）……”编号，**仿宋，三号（16磅），加粗**。
3. **三级标题**：使用“1.……”编号，**仿宋，三号（16磅），加粗**。
4. **段落与缩进**：各级标题均**首行缩进 2字符**，固定行距 **28磅**，段前、段后均为 **0磅**。
5. **防断页控制**：所有层级标题必须启用**“与下段同页（`keep_with_next = True`）”**，严禁标题单独出现在页面最末行。

### （五） 计算公式
1. **排版**：独立成段，居中对齐，无首行缩进，行距固定值 28磅（或单倍行距防止上下截断）。
2. **字体与字号**：仿宋，**14磅**（可根据公式长度适当微调）。
3. **内容要求**：优先使用可编辑的文字公式或 Word 原生公式（OMML）；公式中的指标名称、运算符号和计量单位应清楚完整（如：$\text{HDD}_{20}\text{ 同比增幅(\%)} = (\text{本期HDD}_{20} - \text{同期HDD}_{20}) \div \text{同期HDD}_{20} \times 100\%$）。**严禁将省市平台投诉量与净投诉量相加计算所谓的“投诉合计”**。

### （六） 表格规范
1. **位置与宽度**：表格在页面内水平居中，总宽度严格控制在版心宽度内（**不超过 15.6厘米**）。
2. **列宽分配**：根据各列文字与数值长度合理分配列宽（如首列单位名称适当加宽），避免机械等宽导致数字折行。
3. **字体与字号**：**仿宋，小四（12磅）**。
4. **表头样式**：表头文字**加粗**，填充**浅灰色底纹**（如 `#EDEDED` 或 `#F2F2F2`），黑色文字。
5. **边框样式**：外边框及内部网格线均使用**灰色细实线**（`0.5磅`，颜色 `#808080` 或 `#999999`）。
6. **对齐方式**：单元格内容**水平居中、垂直居中**；首列单位层级从属缩进或较长说明文字可设为左对齐。
7. **单元格段落与行高**：单元格内段前、段后均为 **0磅**，行距**固定值 19磅**；行高随内容自动调整，严禁设置会截断多行表头文字的固定行高。
8. **跨页控制**：启用**“在各页顶端以标题行形式重复出现（`tblHeader`）”**，并设置**“允许跨页断行 = 否（`cantSplit`）”**，确保同一行不跨页拆分。
9. **表下注释**：紧随表格下方，使用**仿宋，小四（12磅）**，无首行缩进，行距固定值 20磅（如庄河环海未结算外购热简注）。
10. **数值精度**：表格内数值统一精度、明确计量单位；计算过程使用原始精度，最终展示时四舍五入。

为确保纸质文档直观易读，应在六大章节正文中对应穿插嵌入 **5～6 幅高分辨率（$\ge 300\text{ DPI}$）统计图表**：
1. **标准配图清单**：
   * **第一章配图（概述必配）**：**《图1 统计周期主城区每日平均气温与同期对比曲线图》**（仅绘制本期日均温与同期日均温双线对比，在 DOCX 概述部分必须嵌入）
   * **第二章配图**：《图2 各单位标煤耗量同比增减分解及计划完成率对比图》
   * **第三章配图**：《图3 期间辽宁电力现货每日96点实时出清电价走势图》（高频 96 点曲线与深谷负电价区间）

2. **纸质图表视觉与配色规范（红增绿减）**：
   * **红增绿减铁律**：所有统计图表柱体、折线及差异率标注严格遵循**“增加为红色、减少为绿色”**原则（增加/上升使用警示红 `#C83E37` / `#DC2626`，减少/下降使用深青绿 `#0F766E` / `#16A34A`），严禁红绿倒置。
   * **画布与排版**：纯白背景（`#FFFFFF`），无外框阴影；图片段落居中对齐、**无首行缩进**，图片宽度设为 **14.8厘米～15.4厘米**（与版心及表格宽度对齐），段前 6磅、段后 4磅。
   * **直接显示数据标签**：因纸质打印无法鼠标悬停看数，所有柱状图、折线图、瀑布图必须**强制开启数据标签（Data Labels）**，字号清晰、不重叠。

   * **图题（图注）格式**：置于图表正下方，居中对齐，无首行缩进，**仿宋，小四（12磅），加粗**，行距固定值 22磅，段后 6磅；图片段落须设置 `keep_with_next = True` 确保图片与下方图题不跨页分离。

### （八） 页码设置
1. **位置与奇偶页**：页码设置在页脚，位于双面打印时每页的外侧；必须启用**“奇偶页不同”**：**奇数页右对齐，偶数页左对齐**。
2. **页码格式**：`-1-`、`-2-`、`-3-`，数字两侧使用半角连字符 `-`，中间**不加空格**。
3. **字体与字号**：**Times New Roman，小四（12磅）**，常规字重，黑色。
4. **边距与段落**：页脚距页面底端 **1.8厘米**；页码段落无首行缩进，段前、段后均为 **0磅**。
5. **连续编号**：使用 Word 自动页码域（`PAGE`），从正文第一页开始编号为 `-1-`，后续连续编号；**不启用“首页不同/首页隐藏页码”**；若文档分节，页码保持连续。
6. **落款（文末）**：全文末尾右下角标注编制部门（如“经济运行部”）与报告生成日期（如“2026年11月6日”），仿宋三号，右对齐（右侧空 2～4 字符），段前 14磅。
