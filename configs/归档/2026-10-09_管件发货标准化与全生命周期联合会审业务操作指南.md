# 📘 洁净能源集团2026年度保温管物流链协同作业指南
## ——“管件发货标准化核验”与“订单流转全生命周期联合会审”操作白皮书

---

### 【前言：从经验填报到数字契约】

在供暖管网升级改造与保供工程中，生产、物流与施工涉及集团管理部、各大保供厂家（如开元、鑫瑞得、天地龙等）、监理单位及各施工标段（高温水标段、一次网/二次网工区等）多方主体。过去在数据交接过程中，常常面临两大管理痛点：

1. **物料口径不一、库存对不上账**：各厂家线下填报习惯各异，有的写“90°保温弯头”，有的写“DN50 弯头 90度”，有的简写“大小头”。一旦录入非标名称，下游施工标段无法合规验收，集团大屏无法科学汇总，更导致厂区成品库存无法联动自动扣减。
2. **在途纠错口头沟通、缺乏共识与留痕**：运输过程中一旦发现数量少装、规格选错或车牌填错，过去往往通过微信或电话单方联络，甚至私下找管理员在后台改库。这种方式不仅存在严重的合规审计漏洞，还极易引发各方责任推诿。

针对上述痛点，系统正式上线并深度优化了两大核心机制：
* **发货端【管件标准化校验与智能匹配】**：源头规范物料口径，锁定价格库物理特征，精准扣减厂区库存；
* **流转端【全生命周期联合会审机制】**：线上阳光纠错，业务状态安全冻结，多方共识全票生效，全程留痕终身免责。

## 第一篇：发货端【管件标准化校验与智能匹配】机制

### 一、它究竟在干什么？
当厂家业务员在“发货管理”界面录入或从 Excel 批量粘贴管件发货清单时，系统会自动调取该厂家在本项目中的《中标价格库/标准物料库》。

系统内嵌的**物理特征语义识别引擎**会自动提取用户录入内容的底层“物理 DNA”（包括：管件大类、公称通径 DN、折弯角度°、弯曲半径 R、三通子类型等），将各种口语化、简写化的录入内容**精准对齐**到正规的中标标准型号。

### 二、为什么这样设置？（核心业务逻辑）

#### 1. 严格保障厂区成品库存自动扣减真实有效
* **采纳标准型号（🟢 扣减库存）**：厂家在平台维护的厂区库存盘点表均以“标准物料”为基准。只有当发货明细成功对齐中标库标准型号时，发货出厂才会自动在厂家成品库存中扣减对应件数；
* **保留原始非标（⚪ 不扣减库存）**：如果发货项为特殊加工件或未收录的非标物料，系统允许保留原填报发货，但在库存体系中**明确不执行扣减**，并在后台打标为非标件，杜绝账实混乱。

#### 2. 精细化物理属性防错，杜绝“拉错货、扣错库”
经过最新优化，匹配引擎执行严格的“物理属性一致性校验”：
* **角度强校验**：录入“90°预制保温弯头”时，系统绝不会因同属 DN50 口径而错误首选“45°弯头”；
* **子品类强隔离**：录入“跨越三通”时，绝不会与普通“直三通”混淆；
* **双口径降序规范**：变径管或三通双口径（如 DN100/DN50）自动对齐，杜绝反向或无序干扰。

### 三、一线发货人员如何操作？

#### 模式 A（推荐：使用发货助手快速点选）
1. 打开页面：导航至【发货管理】页面，切换到【管件发货】标签页；
2. 打开助手：点击表格上方的快捷按钮 **【📦 标准管件库选择】**；
3. 检索与勾选：
   * 弹窗左侧或顶栏支持按品类切换（弯头、三通、变径管、球阀等）；
   * 在搜索框中输入规格（如输入 `50` 或 `90`），列表秒级过滤；
   * 点击数量步进器直接输入本次发货件数；
4. 导入表格：点击右下角 **【导入所选管件到表格】**，系统自动将选中的标准管件填入表格，计量单位统一合规规范。

#### 模式 B（自由填报 / Excel 复制粘贴）
1. 在表格中填写：在电子表格内直接输入或从线下 Excel 复制粘贴“管件类型”、“型号/规格”、“发货数量”；
2. 点击提交发货：填好车牌、联系人、发货备注后，点击底部的 **【🚚 提交发货单】**；
3. 进入智能审核弹窗：系统自动弹出 **【整车管件发货核对确认】** 窗口：
   * **场景 1（完全吻合）**：如填写的“90°预制保温弯头 · DN50”与中标库完全一致，条目直接高亮显示，并标注“🟢 扣减库存”；
   * **场景 2（存在多个合理候选）**：若填报较模糊（例如只写了“保温弯头 · DN50”未注明角度），下拉菜单会智能提示“45°”或“90°”，由发货员手动选定；
   * **快捷批量操作**：弹窗顶部提供 **【✨ 全部采纳标准】** 与 **【📝 全部保留原样】** 按钮，支持一键批量确认；
4. 确认出厂：核对底部扣减库存与不扣减库存的统计无误后，点击 **【确认无误，提交发货】**，发货单正式录入系统。

## 第二篇：流转端【全生命周期联合会审机制】

### 一、它究竟在干什么？
直管与管件发货出厂后，在进入施工标段交付的过程中，流经**待到货、待接收、待入库**三大核心环节。

过去，一旦出现数据填报失误，业务人员往往私下要求管理员改数。现在，平台建立了一套**“阳光在线圆桌会议”机制——联合会审**：
任何一方发现正当的修正诉求，均可在系统内发起会审提案；涉及利益的各方在线查看对比并进行表决；**全票同意后，系统自动生效更正，秒级恢复流程**。

### 二、为什么这样设置？（核心业务保障）

| 设计维度 | 传统私下改数模式 | 联合会审机制 | 业务价值 |
| :--- | :--- | :--- | :--- |
| **数据安全性** | 单方可私自修改或私下托人改库 | 任何修改必须全流程公开提案并经过多方表决 | 消除权力寻租与私下改账风险 |
| **业务一致性** | 一方正在改数，下游施工方已将错误数据入库 | 发起会审即刻**冻结订单状态**，期间禁止接收入库 | 杜绝并发业务冲突，锁死风险窗口 |
| **权责与合规** | 出错后各执一词，无法界定谁的责任 | 详细记录发起人、更正前后数值、每位投票人的意见 | **共识免责、全程留痕**，终身可审计 |
| **处理时效** | 线下反复电话请示、签字盖章周期长 | 移动端/电脑端在线收到通知红点，一键表决，全票即刻生效 | 业务响应由“天级”缩短至“分钟级” |

### 三、各角色全流程操作指引

```
┌────────────────┐       ┌────────────────┐       ┌────────────────┐
│   发现数据有误  │ ────> │   发起联合会审  │ ────> │  订单在审冻结  │
│ (发货/接收/监理) │       │ (勾选明细+填事由)│       │ (下游暂停接收) │
└────────────────┘       └────────────────┘       └───────┬────────┘
                                                          │
                                                          ▼
┌────────────────┐       ┌────────────────┐       ┌────────────────┐
│  自动解冻更正  │ <──── │    全票同意    │ <──── │ 关联各方表决   │
│ (流转恢复正常) │       │ (任一反对则终止)│       │ (会审大厅在线投)│
└────────────────┘       └────────────────┘       └────────────────┘
```

#### 1. 提请人：如何发起会审？
* **谁能发起**：发货单位、收货标段或具备权限的业务经办人（谁先发现谁发起）；
* **操作步骤**：
  1. 在【发货管理】或【需求管理】台账中找到目标车次订单；
  2. 点击操作栏的 **【提请会审 / 发起会审】** 按钮；
  3. 弹出申请表单：
     * **勾选需要更正的明细行**（支持只更正有问题的单项，不影响同车其他无争议项）；
     * **输入更正后数值**：修改“发货量”或“到货量”为实际真实数字，或更正车牌号、到货备注；
     * **填写更正事由（必填）**：如“发货员失误将 80 米误录为 100 米，随车磅单与实物核验确为 80 米”；
  4. 点击提交，提案生成，该车次进入 **“在审冻结（Under Review）”** 状态。

#### 2. 表决人：如何参与投票？
* **谁来表决**：系统根据提请订单管辖的标段与主体，精准划定圆桌表决资格人（包含关联标段施工负责人、供货厂家负责人等）；
* **操作步骤**：
  1. **消息感知**：有待办议案时，系统右上角消息铃铛呈现红点；
  2. **进入大厅**：点击左侧主菜单 **【🏛️ 联合会审大厅】**；
  3. **定位待办**：切换至 **【待我表决】** 选项卡；
  4. **研判对比**：点击议案卡片展开明细，界面清晰展现：
     * 原始值 vs 申请修正值（以红绿高亮对照呈现）；
     * 发起人与提请陈述事由；
  5. **行使表决**：
     * **投赞成票**：点击 **【🟢 同意】**，表示认可该修正；
     * **投反对票**：点击 **【🔴 反对】**，系统要求必须输入反对原因，防止无理阻挠；
     * *(注：在所有人投票结束前，表决人若发现误操作，可随时点击【重新表决】修改投票)*。

#### 3. 会审结论与自动生效
* **全票同意**：
  * 当所有法定资格人均投下“同意”票后，系统立即通过后台原子事务生效；
  * 正式台账中的发货量/到货量等数值瞬间更新为修正值；
  * 订单自动解除冻结，恢复至原待办节点（如继续待到货或待接收），下游标段可无缝继续操作；
* **任一反对（议案终止）**：
  * 若有任何一方投下“反对”票，议案自动关闭为“已终止/已否决”；
  * 订单即刻解除冻结，数据**完全保留初始原值**不变，保护双方既有事实；
* **发起人主动撤回**：
  * 若发起人在表决完成前发现申报有误，可点击【撤回议案】，订单立即安全解锁恢复。

## 第三篇：常见热点疑问与避坑指南 (FAQ)

### Q1：为什么我发货时选了“保留原样”，系统提示“不扣减库存”？
> **答**：厂家成品库存系统是以中标标准物料建立账本的。非标件没有对应标准物料科目，系统无法盲目猜测扣减哪一个规格的库存。如果确实是厂区正规生产的标准件，请在提交弹窗中选择“标准型号”或点击“✨ 全部采纳标准”，即可联动扣减库存。

### Q2：发起的会审一直没有通过，导致现场无法办理接收入库怎么办？
> **答**：会审期间订单被严格冻结，以防止数据在修改中途被下游错误消费。请及时联系关联标段的表决责任人，进入【联合会审大厅】的【待我表决】中投下同意票。若遇表决人员出差、离职或紧急异常争议，可提请集团超级管理员执行合规仲裁通道。

### Q3：为什么表决必须“全票同意”才能生效？
> **答**：保温管与管件具有高价值和强结算属性。发货量与到货量直接挂钩工程款结算与进度款支付。任何一方私下更正都不具备公信力，只有供货方与接收方均明确签字认可，才能形成免责的法律与审计闭环。

### Q4：会审支持修改哪些内容？可以多次发起吗？
> **答**：支持修正发货数量、到货数量、车牌号、到货备注等关键字段。针对同一车次，一次只能存在一个进行中的会审议案（通过事务锁保证一致性）；前一次议案办结（通过或否决）后，若后续环节再次发现客观错误，依然可以依规提请新的会审。
