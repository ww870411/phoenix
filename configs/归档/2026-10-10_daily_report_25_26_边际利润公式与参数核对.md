# 2025—2026供暖期生产日报：边际利润公式与两期参数核对

核对日期：2026-10-10。项目：daily_report_25_26。输入为本机 phoenix_db / phoenix / public 当前实际表、pg_get_viewdef 实际视图定义和仓库项目配置。这里的两期参数是当前数据库保存的值，不能据此证明过去每一天页面使用的参数版本。

## 一、结论与基础公式

所有金额结果单位为万元。

```text
边际利润 = 直接收入 − 非煤成本 − 标煤耗量 × 标煤单价 / 10000
可比煤价边际利润 = 直接收入 − 非煤成本 − 标煤耗量 × 可比标煤单价 / 10000
可比煤价边际利润 − 边际利润 = 标煤耗量 × (标煤单价 − 可比标煤单价) / 10000
直接收入 = 售电收入 + 内售热收入 + 暖收入 + 售高温水收入 + 售汽收入
非煤成本 = 天然气成本 + 外购电成本 + 购水成本 + 可计量辅材成本 + 外购热成本 + 内购热成本
```

可比煤价只替换煤价，其余参数仍用对应年度、对应单位常量。六家有煤耗单位两期可比标煤单价均为1000元/吨。

## 二、收入与成本逐项展开

| 项目 | 公式（万元） | 原始量/常量字段 |
| --- | --- | --- |

| 内售热收入 | 供热量（GJ）×内售热单价÷10000 | amount_heat_supply × price_inner_heat_sales / 10000 |
| 暖收入 | 采暖期供暖收入（万元）×计入天数÷156 | eco_season_heating_income × 天数 / 156 |
| 售高温水收入 | 高温水销售量（GJ）×售高温水单价÷10000 | amount_hot_water_sales × price_hot_water_sales / 10000 |
| 售汽收入 | 售汽量（吨）×售汽单价÷10000 | amount_steam_sales × price_steam_sales / 10000 |
| 煤成本 | 标煤耗量（吨）×标煤单价÷10000 | consumption_std_coal × price_std_coal / 10000 |
| 可比煤成本 | 标煤耗量（吨）×可比标煤单价÷10000 | consumption_std_coal × price_std_coal_comparable / 10000 |
| 天然气成本 | 耗天然气量×购天然气单价÷10000 | consumption_natural_gas × price_natural_gas / 10000 |
| 外购电成本 | 外购电量（万kWh）×外购电单价（元/kWh） | consumption_purchased_power × price_purchased_power |
| 购水成本 | 耗水量（吨）×购水单价÷10000 | consumption_water × price_purchased_water / 10000 |
| 外购热成本 | 外购热量（GJ）×外购热单价÷10000 | consumption_outer_purchased_heat × price_outer_purchased_heat / 10000 |
| 内购热成本 | 网口供热量（GJ）×内购热单价÷10000 | amount_network_interface_heat_supply × price_inner_purchased_heat / 10000 |

辅材成本 = （耗酸量×酸价 + 耗碱量×碱价 + 耗油量×油价 + 耗氨水量×氨水价 + 耗石灰石量×石灰石价 + 耗石灰石粉量×石灰石粉价 + 耗氧化镁量×氧化镁价 + 耗脱硝剂量×脱硝剂价）/10000。各耗量为吨、单价为元/吨。氨水字段为 consumption_ammonia_water 配 price_n_ammonia_water，须保留该名称差异。

## 三、各单位适用口径

- 北海、香海：直接收入主要为售电与内售热，煤、水、电、辅材成本按各自常量计算。北海的热电联产和水炉底表在公司视图按 company 聚合；专用 analysis_beihai_sub_daily / sum 视图按 sheet_name 分别计算，均共用 BeiHai 常量，不要把公司合计与两个分口径再次相加。
- 金州、北方：暖收入、售电、高温水收入按各自年度常量计算；煤、水、电、辅材按基础公式。
- 金普：暖收入、高温水收入及煤、水、电、氧化镁、脱硝剂成本按基础公式。
- 庄河：暖收入及煤、水、电、氧化镁、脱硝剂、外购热成本按基础公式。利润使用 consumption_std_coal，而不是张屯专用煤耗字段；看板“标煤耗量汇总(张屯)”是另一指标，不能直接代替利润煤耗。
- 研究院：当前未配置两种煤价，基础公式仍包含煤成本项，缺失常量按0处理；当前两种利润因此相同。不要把未配置解读为市场煤价为0。
- 供热公司：暖收入按固定156天分摊，两项销售收入直接读取日报金额；扣除内购热、水、电成本。当前未配置两种煤价，两个利润相同。
- 十个分中心在 sum_basic_data 和公司分析视图可按自身 company 常量计算。集团汇总只纳入供热公司合计，不再叠加分中心，避免重复。

## 四、汇总抵销公式

```text
主城区 = 北海 + 香海 + 供热公司
主城区边际利润 = 三家边际利润之和 + 三家内购热成本之和 − 三家内售热收入之和
主城区可比煤价边际利润 = 三家可比煤价边际利润之和 + 三家内购热成本之和 − 三家内售热收入之和
集团 = 北海 + 香海 + 供热公司 + 金州 + 北方 + 金普 + 庄河 + 研究院
集团边际利润 = 八家边际利润之和 + 八家内购热成本之和 − 八家内售热收入之和
集团可比煤价边际利润 = 八家可比煤价边际利润之和 + 八家内购热成本之和 − 八家内售热收入之和
```

groups、analysis_groups_daily、analysis_groups_sum 当前定义均采用以上抵销。主城区和集团没有独立煤价，应逐单位计算再汇总。主城区展示表的“热电厂”口径读取北海+香海利润之和，与主城区三家抵销后的利润不同。售电公司不在上述集团视图成员清单中。

## 八、期间、取值及复算注意事项

- 本期常量按 period=25-26，同期按24-25，各自通过company、item关联，视图按MAX(value)选取。本次两期常量无company+item+period重复记录。
- 供暖期标识以10月1日为年度分界；同期日期为本期日期减一年。查询去年项目时必须指定历史业务日期，否则当前日期可能落入26-27期。
- sum_basic_data 的供暖期累计起点固定为2025-11-01 / 2024-11-01。单日暖收入计1天，近7日计7天，本月累计计月初至业务日期天数，供暖期累计计11月1日至业务日期天数。
- analysis_company_sum 的暖收入计查询区间含首尾的自然日数，常量按区间结束日期确定年度；并非按实际填报天数分摊。两条视图链路均固定除156，不自动按采暖季长度调整。
- 电量为万kWh时直接乘元/kWh得到万元；改用kWh时需除10000。煤、水、热、辅材量则按表中公式除10000。
- 庄河24-25外购热单价实际为NULL，系统将其按0计算；25-26为47.71元/GJ。另行经济测算若采用真实同期外购热价格，应显式输入，不应无说明复用0。
- 可比煤价指标只消除煤价变化，售电价、外购电价、辅材价、供暖收入等两期差异仍在。
- 本次只读核对，没有修改表数据、视图、接口、业务代码。浏览器连接错误使页面可见内容未验收；配置、服务和实际数据库已核对。
