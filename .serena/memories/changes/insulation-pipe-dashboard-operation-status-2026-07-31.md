# 保温管看板运营状态三档动态分级

日期：2026-07-31（Asia/Hong_Kong）

## 变更
- 前端 `DashboardView.vue` 将固定“运营状况：极佳”改为基于看板实时汇总的“极佳 / 正常 / 需要关注”三档。
- “正常”是默认正向状态，覆盖未开工、无三日计划、样本不足和轻微波动，避免启动期的零值被误报。
- “需要关注”仅在存在未来计划且硬缺口大于 0、SSR 或 PCR 低于 80%，或已有至少 3 单履约样本而 OTD 低于 80% 时触发。
- “极佳”要求存在未来计划、硬缺口及净缺口均为 0、PCR 不低于 95%、SSR 不低于 90%，且三单以上履约样本时 OTD 不低于 90%。

## 影响与验证
- 仅变更前端展示和说明文档；未变更后端接口、数据库或库存计算。
- 当前运行数据无未来三日计划，按规则应显示“运营状况：正常”。
- `frontend` 执行 `npm run build` 通过。
